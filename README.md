# CS-250: Software Development Lifecycle

## Southern New Hampshire University

**Course:** CS-250 – Software Development Lifecycle

**Program:** Bachelor of Science in Computer Science, Concentration in Software Engineering

## Repository Overview

This repository is part of my computer science portfolio at Southern New Hampshire University (SNHU). It contains coursework and project artifacts demonstrating my understanding of the software development life cycle (SDLC), Agile methodologies, and the Scrum framework.

## Course Project

During this course, I worked on the SNHU Travel application project, which involved applying Agile and Scrum practices to software development.

The project included developing user stories, identifying acceptance criteria, participating in Scrum activities, and reflecting on the responsibilities of the Product Owner, Scrum Master, Developer, and Tester.

## Portfolio Purpose

The purpose of this repository is to document my academic progress, demonstrate my software development knowledge, and showcase my ability to apply Agile principles to real-world software development scenarios.

Additional project artifacts and reflections will be added as I complete my coursework.
